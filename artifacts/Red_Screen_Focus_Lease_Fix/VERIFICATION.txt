ROOT CAUSE
SteamVR extended mode renders dark red whenever Headset Window is not the foreground fullscreen compositor. The previous focus-isolation change made that window permanently non-activating. The older implementation fixed red by repeatedly stealing desktop focus. The new implementation leases foreground only while the hardware report state bit says the HMD is worn, then restores the previous desktop window when removed. It also stops treating the raw proximity value (~39k at rest) as a boolean threshold (>300), which had made worn permanently true.
